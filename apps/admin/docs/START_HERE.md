# START HERE — Veste Bem Admin

Leia integralmente o arquivo:

docs/Veste_Bem_Documento_Mestre_Codex_V3_1.md

## Objetivo

Construir o sistema administrativo interno da Veste Bem seguindo exatamente a documentação do projeto.

## Regra principal

Não construir o sistema inteiro de uma vez.

O desenvolvimento deve ser feito em fases, sempre aguardando aprovação ao final de cada fase.

## Tecnologias

* HTML
* CSS
* JavaScript
* Supabase
* Netlify ou Vercel

## FASE 1 — Planejamento técnico e arquitetura

Nesta fase, faça apenas:

* Ler toda a documentação
* Entender o escopo completo
* Propor arquitetura do projeto
* Propor estrutura final de pastas
* Definir organização dos módulos
* Definir organização dos arquivos CSS
* Definir organização dos arquivos JavaScript
* Definir estratégia de integração com Supabase
* Definir estratégia de autenticação
* Definir padrão de nomes
* Definir padrão de componentes
* Definir ordem das próximas fases

## NÃO fazer na FASE 1

* Não criar telas
* Não criar HTML funcional
* Não criar CSS completo
* Não criar JavaScript funcional
* Não criar banco de dados
* Não criar SQL
* Não criar dados fake
* Não implementar localStorage
* Não implementar autenticação
* Não implementar dashboard
* Não implementar módulos

## Entrega esperada da FASE 1

Ao final, entregue apenas:

1. Resumo do entendimento do sistema
2. Arquitetura proposta
3. Estrutura de pastas proposta
4. Lista dos módulos
5. Lista de arquivos que serão criados nas próximas fases
6. Sequência de desenvolvimento recomendada
7. Pontos de atenção antes da FASE 2

Depois pare e aguarde aprovação.
