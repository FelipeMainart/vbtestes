# Veste Bem E-commerce

Storefront Next.js da Veste Bem, organizado como monólito modular orientado a features.

## Comandos

```bash
npm run dev
npm run lint
npm run typecheck
npm run format:check
npm run build
```

## Documentação

Antes de alterar o projeto, leia os documentos oficiais em [`docs/`](./docs/), começando pelo [`06-prompt-mestre.md`](./docs/06-prompt-mestre.md).

## Estrutura

A fundação segue `domain/application/infrastructure/presentation` dentro de cada feature. Diretórios transversais possuem apenas contratos documentais e placeholders; nenhuma integração ou regra comercial foi antecipada.
